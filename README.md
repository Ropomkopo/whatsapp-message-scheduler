# whatsapp-message-scheduler 📱🕰️

Автоматизований планувальник для WhatsApp. Дозволяє налаштовувати точний розклад (через cron) для автоматичної відправки повідомлень вашим контактам.

## Особливості
- 📅 **Відправка за розкладом**: Використовує зручний формат [cron](https://crontab.guru/) для точного планування відправки.
- 🌐 **Веб-інтерфейс (Нове!)**: Зручна панель керування для прив'язки акаунту через QR-код та управління завданнями прямо в браузері.
- 👥 **Багатокористувацькість**: Можливість паралельно підключати кілька сесій WhatsApp (окремих номерів) в одній програмі.
- 🔐 **Безпека**: Авторизація відбувається локально, сесії зберігаються ізольовано одна від одної.

## Вимоги (Prerequisites)
- [Node.js](https://nodejs.org/) (версія 16+).
- Встановлений **Google Chrome** на вашому комп'ютері.

## Встановлення

1. Зклонуйте репозиторій:
```bash
git clone git@github.com:Ropomkopo/whatsapp-message-scheduler.git
cd wa-sender
```

2. Встановіть залежності:
```bash
npm install
```

## Запуск (Веб-інтерфейс) 🚀
Це найзручніший спосіб використання сервісу з графічним інтерфейсом.

1. Запустіть веб-сервер командою:
```bash
node server.js
```
*(Сервер запуститься на порту 3005 за замовчуванням)*

2. Відкрийте у браузері сторінку: **http://localhost:3005**
3. **Авторизація:** Відскануйте QR-код, який з'явиться на екрані, за допомогою вашого додатка WhatsApp (Налаштування -> Пов'язані пристрої -> Прив'язати пристрій).
4. **Управління завданнями:** Після успішної авторизації розблокується права панель, де ви зможете додавати нові завдання (Кому, Час Cron, Текст) та видаляти існуючі.

> ℹ️ *Порада: Якщо ви натиснете "Вийти" у WhatsApp на телефоні, сесія автоматично очиститься, і ви зможете згенерувати новий QR-код однією кнопкою в інтерфейсі без падіння сервера.*

## Запуск (Локальний скрипт) 💻
Якщо ви хочете використовувати стару версію без інтерфейсу (лише через термінал та файл):

1. Налаштуйте завдання у файлі `tasks.json` (у кореневій папці):
```json
[
  {
    "phone": "+380933927991",
    "cron": "5 23 * * *",
    "message": "Привіт! Це заплановане повідомлення."
  }
]
```
2. Запустіть скрипт:
```bash
node index.js
```
3. Відскануйте QR-код прямо в терміналі і не закривайте його.

## Технології
- **Node.js, Express, Socket.io** — Серверна частина та реал-тайм обмін даними.
- **whatsapp-web.js** — Бібліотека для роботи з WhatsApp Web.
- **node-cron** — Планувальник завдань.
- **HTML/CSS/JS** — Сучасний Glassmorphism фронтенд без фреймворків.
