# wa-sender 📱🕰️

Автоматизований сервіс для відправлення запланованих повідомлень у WhatsApp у визначений час за допомогою Node.js.

## Особливості
- 📅 **Відправка за розкладом**: Використовує зручний формат [cron](https://crontab.guru/) для точного планування відправки.
- 🔐 **Збереження сесії**: Авторизація відбувається лише один раз через QR-код у терміналі, після чого сесія безпечно зберігається локально.
- ⚙️ **Просте налаштування**: Усі завдання та повідомлення зберігаються у зрозумілому форматі `JSON`.
- 💻 **Використання системного браузера**: Налаштовано на використання вже встановленого Google Chrome для стабільної роботи (за замовчуванням шлях macOS).

## Вимоги (Prerequisites)
- [Node.js](https://nodejs.org/) (версія 16+).
- Встановлений **Google Chrome** на вашому комп'ютері.

## Встановлення

1. Зклонуйте репозиторій:
```bash
git clone git@github.com:Ropomkopo/wa-sender.git
cd wa-sender
```

2. Встановіть залежності:
```bash
npm install
```

## Налаштування завдань (tasks.json)

Усі заплановані повідомлення налаштовуються у файлі `tasks.json`. Файл має знаходитися у кореневій папці проєкту.

Приклад структури:
```json
[
  {
    "phone": "+380933927991",
    "cron": "5 23 * * *",
    "message": "Привіт! Це заплановане повідомлення."
  },
  {
    "phone": "380123456789",
    "cron": "0 9 * * 1-5",
    "message": "Доброго ранку! Бажаю гарного робочого дня!"
  }
]
```

- **`phone`**: Номер телефону отримувача у міжнародному форматі (з `+` або без нього, скрипт автоматично очистить номер від зайвих символів).
- **`cron`**: Час відправки у стандартному форматі Cron (наприклад, `5 23 * * *` — кожного дня о 23:05; `0 9 * * 1-5` — о 9:00 по буднях). Можна використовувати [crontab.guru](https://crontab.guru/) для створення правильного розкладу.
- **`message`**: Текст вашого повідомлення.

## Запуск сервісу

Щоб запустити бота, виконайте команду:
```bash
node index.js
```

**При першому запуску:**
1. У терміналі з'явиться великий QR-код.
2. Відкрийте **WhatsApp** на вашому телефоні.
3. Перейдіть до **Налаштування** -> **Пов'язані пристрої** -> **Прив'язати пристрій**.
4. Відскануйте QR-код з терміналу.

Після успішної авторизації скрипт завантажить завдання та перейде у режим очікування. **Не закривайте процес (вікно терміналу)**, інакше скрипт зупиниться і повідомлення не будуть відправлені.

> ℹ️ *Порада: Для того, щоб скрипт працював у фоні постійно, ви можете використовувати менеджери процесів, такі як [pm2](https://pm2.keymetrics.io/) (`npm install -g pm2` та `pm2 start index.js`).*

## Технології
